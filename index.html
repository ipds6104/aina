⚠️ TANTANGAN OPERASIONAL DAERAH

Realitas Lapangan: Beban Bertambah, SDM Terbatas

Satuan kerja BPS di tingkat Kabupaten/Kota menghadapi tantangan ganda: tuntutan output statistik berkualitas tinggi yang terus bertambah, berhadapan langsung dengan keterbatasan jumlah aparatur organik.

  • Volume Kegiatan Masif: Sensus Ekonomi 2026, Sakernas, Susenas, Seruti, dan survei rutin berjalan paralel sepanjang tahun.
  • Jumlah Pegawai Terbatas: Satu orang staf fungsional sering kali merangkap berbagai peran teknis dan kepanitiaan sekaligus.
  • Defisit Waktu Analisis: Energi terkuras untuk urusan klerikal mekanis (pembuatan ratusan SPK/BAST honor, cek POK manual, rekap chat WA).
  • Risiko Human Error: Beban kerja berlebih memperbesar peluang salah hitung honor mitra atau keterlambatan laporan dinas.

Tren Global: Dari Chatbot Menuju "Company Brain"

Chatbot Konvensional (Lama)

  • Pasif, hanya menunggu pertanyaan pengguna
  • Hanya mengandalkan data umum internet yang umum
  • Tidak memahami dokumen internal, POK, dan SOP dinas
  • Rawan "halusinasi" saat ditanya angka anggaran atau jadwal
  • Tidak memiliki kemampuan mengeksekusi aksi nyata di terminal

Company Brain Paradigm (Aina)

  • Proaktif, terhubung langsung ke alur kerja harian WhatsApp
  • Single Source of Truth institusi (POK SAKTI, jadwal, SOP)
  • Memahami struktur organisasi, wewenang, dan relasi kerja staf
  • Beroperasi deterministik & zero-hallucination berbasis dokumen
  • Mampu mengeksekusi skrip, query data lake, dan browser headless

🛡️ INTEGRITAS DATA RESMI

Menjamin Ketepatan: Zero Hallucination

Di lingkungan pemerintahan, akurasi angka anggaran dan tanggal kegiatan adalah harga mati. Aina menerapkan arsitektur Strict Grounding untuk menjamin kebenaran informasi:

  • Deterministic Retrieval: Aina wajib mengambil data langsung dari file POK SAKTI dan basis data resmi; dilarang keras menebak angka pagu atau honor.
  • Epistemic Humility (Disiplin Tabayyun): Jika instruksi ambigu atau data belum tercantum di Company Brain, Aina menanyakan klarifikasi secara santun dan tidak berspekulasi.
  • Audit Trail Version Control: Setiap mutasi dokumen dicatat dalam riwayat Git commit yang transparan, dapat diaudit, dan dapat di-rollback kapan saja.

Fakta Arsitektur: Didukung Antigravity CLI

Sinergi dua teknologi inti: performa tingkat rendah Rust dan kecerdasan agentik Google

⚒️

Aina Core Daemon (Rust)

Beroperasi 24/7 di server lokal. Mengatur gerbang webhook WhatsApp, memvalidasi profil dan wewenang lawan bicara, menyaring etika percakapan kerja, dan mengelola task scheduler persisten.

🔮

Google Antigravity CLI (agy)

Mesin agen AI tingkat lanjut yang menjadi 'otak' penalaran. Mampu memanggil ratusan tools dinamis, mengeksekusi terminal bash, menjalankan skrip Python, dan mengontrol Chromium headless.

🧩

Extensible Skill Framework

Keahlian baru ditambahkan secara modular via folder skills/ tanpa merestart server. Siap dikembangkan sesuai kebutuhan spesifik masing-masing satker BPS.

Nilai Manfaat untuk Seluruh Tim Satker

Solusi yang dirancang spesifik untuk menjawab kebutuhan masing-masing fungsi di BPS

👔 Kepala Satker (Pimpinan)

  • Executive summary visual di WhatsApp 3x sehari tanpa perlu menagih
  • Peringatan dini wilayah/kecamatan dengan deviasi target kritis
  • Pemantauan realisasi serapan anggaran POK secara transparan

💼 Bagian Umum & Keuangan

  • Otomasi berkas kontrak SPK & BAST honor mitra via Dokter V
  • Cek instan pagu POK, translok lokal, dan alokasi paket meeting
  • Reminder otomatis H-3 sebelum batas revisi anggaran dan SPK

📊 Bidang Teknis (Sosial/Prod/Dist/Neraca)

  • Live monitoring prelist Google Sheet per kecamatan secara otomatis
  • Deteksi anomali data (NIK ganda, usaha tanpa identitas standar)
  • Broadcast capaian harian transparan ke grup koordinasi lapangan

💻 Tim IPDS (Provinsi & Kab/Kota)

  • Stack 100% self-hosted di ThinkStation lokal, kedaulatan data terjaga
  • Engine data lake DuckDB (<50MB RAM) untuk jutaan data mikro
  • Arsitektur terbuka siap direplikasi ke seluruh satker < 1 jam

Kedaulatan Data & Keamanan Berlapis

Standar keamanan kedaulatan data statistik nasional di lingkungan server lokal

🔒

100% On-Premise & Self-Hosted

Beroperasi di server fisik lokal ThinkStation P320. Seluruh database, token otentikasi, dan memori obrolan berada di dalam perimeter jaringan kantor yang aman.

🛡️

Zero Trust Guard (`data_guard`)

Otoritas berjenjang (Admin, Staff, Guest). Script data_guard.py secara deterministik mencegah pembocoran data mikro atau dokumen internal ke pihak luar.

⚡

Crash-Resilient WAL Storage

Basis data SQLite mode WAL dan DuckDB berbasis disk kebal terhadap korupsi data saat terjadi gangguan pasokan listrik server secara tiba-tiba.
